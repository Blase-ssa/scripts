Задача.
Написать скрипт на bash с TUI на основе whiptail.
Скрипт должен предлагать создать ZRAM диски.
требуется 2 диска:
1 - как swap что бы уменьшить использования swap на жёстком диске.
2 - /mnt/zram должен быть смонтирован в zram диск, но не всегда: пользователю должен даваться выбор.

swap раздел по умолчанию рассчитывается по формуле:
Если RAM меньше 1 ГБ то ZRAM диск для swap = 20% от RAM
Если RAM больше 1 ГБ, но меньше 4 ГБ, то swap = 500 Мб + 2% от RAM
Если RAM больше 4 то swap = 600 Мб + 4% от RAM но не должен превышать 1 ГБ
естественно это должно быть рекомендацией в скрипте, и результат вычислений должен быть введён в поле по умолчанию.

Для /mnt/zram формула следующая:
Если RAM меньше 1 ГБ то ZRAM диск для swap = 50 Мб
Если RAM больше 1 ГБ, но меньше 2 ГБ, то swap = 100
Если RAM больше 2 ГБ, но меньше 4 ГБ, то swap = 200 Мб
Если RAM больше 4 то swap = 600 Мб + 4% от RAM но не должен превышать 1 ГБ

по результатам работы Install скрипта пользователю должен быть предоставлен выбор если он хочет установить unit файл по месту назначения.
Так же должен быть сгенерирован файл rampak.sh который и отвечает за текщее поведение.

кроме того. скрипт rampak.sh должен иметь возможность смонтировать папки:
* /var/logs в /mnt/zram/logs
* /tmp в /mnt/zram/tmp

так же скрипт после создания/монтирования /mnt/zram должен создать там папку shared
